# AhorraU: Asistente Inteligente de Finanzas Personales

## Descripción del Proyecto
**AhorraU** nace como respuesta a la problemática que enfrentan muchos estudiantes universitarios: el desconocimiento y la falta de control sobre sus ingresos y gastos. Nuestra solución busca facilitar la gestión financiera personal mediante un asistente inteligente, permitiendo a los usuarios registrar sus movimientos, analizar sus hábitos de consumo y establecer metas de ahorro efectivas.

El sistema utiliza inteligencia artificial para ofrecer recomendaciones personalizadas, ayudando a los estudiantes a tomar mejores decisiones financieras y desarrollar el hábito del ahorro desde una etapa temprana de forma sencilla e intuitiva.

## Nuestra Solución
Desarrollamos una aplicación web moderna que integra:
* **Gestión financiera:** Registro de ingresos, gastos y metas de ahorro.
* **Inteligencia Artificial:** Asistente capaz de analizar hábitos y brindar recomendaciones financieras personalizadas (integración con OpenAI API / Google Gemini).
* **Interfaz intuitiva:** Diseño centrado en el usuario, desarrollado con tecnologías web de vanguardia.
* **Análisis de datos:** Reportes mensuales y gráficos estadísticos para entender el comportamiento de consumo.

## Tecnologías Utilizadas
* **Frontend:** React / Next.js
* **Backend:** Python (FastAPI) o Node.js (Express)
* **Inteligencia Artificial:** OpenAI API o Google Gemini
* **Base de Datos:** MySQL o Firebase
* **Diseño:** Figma
* **Control de versiones:** Git y GitHub
